走进教室、走廊和操场，通过角色移动与场景互动，体验地震避险中的保护动作、撤离选择与同伴线索报告。

- **想了解地震避险主题的玩家**：通过虚构情境，认识不同场景中的行动选择。

## 可以体验什么

- **三张场景地图**：在教室、走廊和操场中移动、观察和互动。
- **保护与撤离情境**：通过场景任务体验保护动作与有序撤离。
- **同伴线索报告**：在互动中关注同伴相关线索，并完成游戏内报告。
- **行动回顾**：回看自己在情境中的行动，作为后续讨论的起点。
- **电脑与手机操作**：电脑可点击地面移动，手机也支持方向按钮。

## 怎么玩

1. 打开游戏，点击地面移动角色；手机可使用方向按钮。
2. 靠近金色光圈，按 **E** 或点击互动按钮，完成场景互动。
3. 在三张地图中体验任务，并查看行动回顾。
