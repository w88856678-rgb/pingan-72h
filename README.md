# 平安72小时 · 走向平安

一款通过角色移动和场景互动练习地震避险的公益教育游戏。

## 开始游戏

[打开《平安72小时》](https://w88856678-rgb.github.io/pingan-72h/)

点击地面移动，靠近金色光圈，按E或点击互动按钮。手机也支持方向按钮。教室、走廊、操场三张地图包含保护动作、有序撤离、同伴线索报告和行动回顾。

本仓库用于发布静态站点。网站无需注册，不调用生成式AI或救援服务；进度仅保存在玩家自己的浏览器。

游戏为虚构教育情境，不能代替专业演练。现实灾害听从当地预警和现场指挥，内容尚未经防灾机构审定。
